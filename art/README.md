# Art

Gabby's own pixel art goes here as Aseprite files (`icon.ase` and the item sprites), each exported
at 512x512 with nearest-neighbour for the icon. The icon in `common/src/main/resources/assets/summiteer/icon.png`
is a first draft of the ice axe; Gabby's `icon.ase` replaces it before the first release. Never
replace her files with generated art.
